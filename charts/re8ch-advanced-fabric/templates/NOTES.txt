Advanced Fabric {{ .Chart.Version }} is installed in observe-only mode by default.

The legacy networking.re8ch.com API is dual-published for this minor release only.
No FRR, nftables, policy-rule, ASN or neighbor mutation is enabled unless both:

  advancedFabric.mode=guarded-apply
  advancedFabric.applyEnabled=true

Inspect status:

  kubectl get advancedfabric.{{ .Values.advancedFabric.apiGroup }} {{ .Values.advancedFabric.instanceName }} -o yaml
  kubectl get trafficpolicies.networking.advfab.org -A
  kubectl -n {{ .Values.advancedFabric.runtimeNamespace }} get pods \
    -l 'app.kubernetes.io/name in (advanced-fabric-controller,advanced-fabric-agent,advanced-fabric-pod-conformance)'

Verify the public observation path:

  ./scripts/verify_mvp.sh {{ .Values.advancedFabric.runtimeNamespace }}
