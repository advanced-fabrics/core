# Contributing

Follow https://github.com/advanced-fabrics/.github/blob/main/CONTRIBUTING.md.
Compatibility, protocol and security-boundary changes require an AFEP. Commits
must include a DCO sign-off and behavioral changes must include tests.

Maintainer-authored, same-repository pull requests receive the
`re8ch-policy-reviewer` check after verified commits and CI pass. This
App-owned check is required for merging; its informational approval is not a
substitute for a human review of external contributions. Maintainers should
bring an accepted external change into a new signed, DCO-compliant PR.
